(1) سیاسی تجزیہ کار

اس زمرے کا اصل مضمون "قازقستان کی سیاست" ہے۔ دو افراد کو ٹیسٹ کی پالیسیوں میں دلچسپی ہے:

* پالیسی *ڈویلپر*: آپ Kubwarden پالیسی لکھ رہے ہیں اور آپ اس بات کو یقینی بنانا چاہتے ہیں کہ آپ کا کوڈ آپ کی توقع کے مطابق چلتا ہے.
* *کلسٹر آپریٹر*: آپ کو ایک Kubwarden پالیسی مل گئی ہے اور آپ اس کی تعیناتی سے پہلے پالیسی کی ترتیبات کی جانچ اور دھن کرنا چاہتے ہیں. آپ اپنے CI / CD پائپ لائنوں، اور دیگر انتظامی کاموں میں ان ترتیبات کی جانچ کرنا چاہتے ہیں.

دستاویزات کے اگلے حصوں سے پتہ چلتا ہے کہ یہ افراد کس طرح Kubiwarden پالیسیوں کی جانچ کرسکتے ہیں.
